# TaskerPH member features

This inventory is for the signed-in `user` role only. It covers both sides of a member account: posting a task and placing an offer on someone else's task. Staff dashboards and administrative controls are excluded.

## Find and evaluate tasks

- Browse live task listings and refresh the marketplace.
- Search task titles, descriptions, places, or skills.
- Filter listings by category and task status.
- Open task details, including budget, location, schedule, description, photos, and checklist items when provided.
- View public member profiles and the reviews and public task history shown on those profiles.
- Bookmark other members' tasks and manage the saved-task list.
- Report a task for scam or fraud, inappropriate content, misleading information, or another concern.

## Post and manage your own tasks

- Publish a task with a title, category, PHP budget, location, and description.
- Add a schedule, checklist, and up to three task photos where the posting form offers those fields.
- Save an unpublished task as a draft, then resume and manage saved drafts.
- View task status and incoming bids in **My tasks**.
- Edit or delete a listing.
- Review bidders' messages and profiles, message bidders, accept an offer, or remove a pending bidder with a reason.
- Track a selected task through its lifecycle; report a problem or cancel an assignment while it is in progress.
- Confirm a tasker's completion request, or report a problem instead.
- Reopen a cancelled task or repost a completed/cancelled task as a new listing where those actions are available.
- Leave a 1–5 star review and optional comment after confirmed completion.

## Place and manage offers

- Submit a PHP offer and message on another member's open task.
- Search and filter **My bids** by bid status and task status.
- Edit or delete a pending offer while the task is open.
- View the task and poster's public profile, and message the poster.
- If selected, coordinate through messages, mark the task as done, report a problem, or cancel the assignment.
- Review the assignment status and leave a review after completion.

## Account and communication

- Register, sign in, and sign out.
- View notifications about messages, bids, task updates, and announcements; mark notifications as read.
- Receive push notifications in supported native app environments when configured and permitted.
- Update your name and profile photo; change your email or password with the account's confirmation flow.
- Choose light/dark appearance and adjust the glass-transparency preference.
- View available legal documents and submit a suspension appeal if that account flow is presented.

Feature availability can depend on the task state, account state, supplied listing details, and platform notification permissions. TaskerPH does not advertise an in-app payment feature in this inventory.
